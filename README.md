# Clinical Data Analyst Portfolio
A collection of cleaning, analysis, and visualisation projects focused on clinical and healthcare data.
Each project follows the same workflow: question → data → cleaning → visualisation → recommendation.

## Projects

| # | Project | Question | Tools | Status |
|---|---------|----------|-------|--------|
| 1 | us_mortality_trends_1999_2017 | How did age-adjusted death rates for influenza/pneumonia and cancer change in the United States from 1999 to 2017, and what factors might explain the difference in their trends? | SQL, Excel, Tableau | In progress 🟠 |

## Workflow

1. Define the clinical or business question
2. Source and inspect the data
3. Clean and transform with SQL
4. Visualise in Tableau
5. Summarise findings and recommendations

## About

I am building this portfolio to demonstrate my transition into a remote clinical data analyst role. It is designed as evidence of how I think, clean data and communicate results.
